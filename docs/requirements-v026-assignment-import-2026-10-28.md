# V026 存量分配批量导入需求与验收基线

日期：2026-10-28。版本：`3.10.0-v026-assignment-import`；新增数据库迁移 V023。用户已确认采用“仅导入通过行”：文件中存在错误时，可以明确确认后只导入通过的记录。

## 业务目标

态势感知设备、社保发卡设备等 IP 已在实际使用，需要补录为系统内“已分配”，防止再次分配；未来使用统一模板重复处理同类存量清单。该操作沿用人工补录的分配与释放生命周期，保留资产、归属、设备资料、责任人和审计记录，不生成申请或伪造审批。

本轮增加通用功能，不自动导入业务表，不覆盖原始文件或现有分配。社保原表记录的是“连接桌面制卡机的 PC IP”，资产名称必须按实际管理口径确认；网点名称不同、重复 IP、空 IP、撤并网点和带前缀地址应先核实再填入标准模板。

## 入口与模板

管理员在“基础资料 → IP 资源池”的地址列表标题右侧进入“批量补录已分配”，下载 CSV 或无宏 XLSX 模板，填写、上传、预览、确认。科技管理员无此权限。任务及结果仅提交管理员本人可查看、确认、取消、下载；其他管理员不能借任务编号读取资料。

单次文件不超过 5 MiB，最多 2000 条数据；错误行或重复行也是数据行，不能借此绕过行数上限。无任何通过行的任务不能确认完成。

模板固定 14 列，按顺序为：IP地址、资产类型、资产名称、支行名称（核对用）、网点名称（核对用）、资源编码、使用人姓名、统一认证号、负责科技管理员账号、交换机IP、交换机端口、MAC地址、设备序列号、补录说明。

XLSX 的“导入数据”页填写记录，说明页与数据分离；数字编码按单元格显示值读取。拒绝公式、外部链接和宏工作簿。CSV 使用 UTF-8，结果下载对以公式字符开头的文本作安全转义，避免打开报表时执行公式。

## 校验与预览

上传只保存预览，不修改分配。逐行显示原始 Excel 行号、IP、资产类型/名称、支行/网点、处理结果、原因及修正建议，并统计总行数、可导入、重复跳过、错误数量。

- IP 必须是池内有效 IPv4；由 IP 唯一定位实际支行、网点，填写的归属名称用于核对。网关、未知 IP、错误归属或已删除组织不能导入。
- 资产类型和名称必须对应启用的资产定义；使用人姓名、统一认证号、资源编码按当前资产规则条件必填或禁止填写。资源编码不能与有效分配或同批其他行重复。
- 责任账号如填写，必须是启用且具有该支行、网点权限的科技管理员。交换机 IP/端口、MAC、序列号、说明沿用现有补录校验和长度限制；MAC 保留原文。
- 同文件同 IP 对应不同资料时，相关行全部报错，避免顺序决定结果。已存在且资料完全一致的人工补录标为“重复跳过”；资料不同的人工补录和所有既有审批分配标为错误，不覆盖。
- 可用、已占用、停用、人工保留 IP 可按现有人工补录规则建立有效分配；系统保留网关始终拒绝。

## 部分导入与二次校验

确认页面明确显示“仅导入通过的 N 行；重复及错误 M 行不会导入”，管理员点击“确认导入通过行（N条）”明确接受部分导入。没有明确接受部分导入时，服务端拒绝写入。

确认在数据库写锁及同一事务内重新核验 IP 状态、既有分配、归属、资产条件和责任账号。若期间发生变化，返回更新后的完整预览和 `requiresReview=true`，递增预览版本，所有行均不写入；管理员必须重新查看并按新版本确认。提交旧版本同样返回需复核，不分配任何新 IP。

通过行全部在一个事务中执行；任一通过行写入失败，整批通过行回滚，不允许只成功其中一部分。完成确认重试直接返回原结果，不重复生成分配或审计。预览及完成后的结果下载仅包括错误行与跳过行，修改后另建任务再次导入；已取消或已失效任务可下载全部未写入行。

## 完成、释放与备份

完成后显示实际导入、重复跳过、错误未导入及未导入合计，刷新资源池和最近记录；任务可以重新打开和下载结果。未确认任务可以取消，取消后不能分配。

分配来源沿用人工补录。可用 IP 释放回可用；“已占用”补录后转为普通分配，释放回可用；停用和人工保留 IP 释放后恢复原状态及保留原因。释放历史必须保留本次资产、责任人、设备资料与说明，不修改既有审批历史。

备份包括新增 `assignment_import_job`、`assignment_import_row` 表。恢复后未完成预览标为 EXPIRED，不能继续确认；已完成记录与分配历史保留。V022 数据库升级至 V023 不修改已有分配、释放或旧迁移文件，重复启动迁移幂等。

## 验收清单

1. CSV/XLSX 模板真实可下载、上传；XLSX 数字格式编码保留前导零，说明页不会被误当作设备；任意页公式和外部链接被拒绝。
2. 混合文件准确分出通过、重复、错误；未确认部分导入零写入；确认后只产生通过行，既有审批及相同人工补录原记录不变。
3. 文件内冲突 IP 全部拒绝；重复资源编码、条件必填、网关、未入池 IP、停用资产、归属错误、无权限责任账号逐项拒绝。
4. 确认前被其他管理员分配、资产规则变化或预览版本过期时，返回更新预览且零写入；复核新版本后可再次确认。
5. 模拟第二条写入失败，全部通过行与占用状态变更回滚；移除故障后任务可重试。完成任务重复确认无重复分配。
6. 管理员本人任务可取消、重开、下载；他人任务拒绝；科技管理员和缺少 CSRF 的 HTTP 写请求拒绝。
7. CSV 结果公式注入被转义，序列号与其他设备资料不泄露到科技管理员接口。
8. 四种补录来源状态经过分配、释放后符合既有规则，释放快照完整；V022→V023 升级幂等且外键、完整性检查通过。
9. 备份含新表，恢复使待确认任务失效并保留完成记录；既有阶段 1–15、阶段 16、真实 HTTP、浏览器与发布包校验全部通过后交付。

后端核心回归由 `StageSixteenAssignmentImportSmokeTest` 在隔离临时数据库执行；HTTP、浏览器与打包校验单独记录实际执行结果。本文是需求与验收标准，不替代实测通过记录。
