# V025 需求与验收基线

确认日期：2026-10-09。用户已确认以下规则并授权实施。开发起点为 V024，数据库 V021；新增连续迁移 V022，不改动已发布迁移和真实业务数据。

## 1. 备份、提醒与恢复

- 所有管理员均可在网页下载完整备份到自己的电脑，覆盖账号、组织、资产、IP、申请、分配、历史、审计与系统设置。科技管理员无备份或恢复权限。
- 默认每 7 天按全系统最近一次成功生成的手动备份计时；任一管理员备份后更新全局时间与操作人。站内提醒可关闭，不强制备份，不阻断任何业务。
- 所有管理员均可上传本系统备份。先校验并预览备份时间、数据版本与覆盖范围，再通过系统对话框明确确认全量恢复；账号、密码、权限及设置也回到备份时状态。
- 恢复前自动保存并验证当前数据的回滚备份；备份失败不得进入替换。恢复期间暂停业务访问，等待正在处理的请求完成；所有数据库连接关闭后才切换数据。
- 恢复成功撤销当前及备份中的全部旧会话，要求用恢复后的账号密码重新登录。恢复失败自动保留或还原原数据；进程中断后启动时按恢复标记回滚，不能留下半套数据库。
- 新备份包含数据、元数据与摘要。兼容校验通过的 V021/V022 完整备份，旧 V021 只在隔离副本升级；不执行可能重置业务数据的更早迁移。恢复操作记录及回滚副本在待覆盖数据库外保留。
- 网页备份不等同 CSV/XLSX 导出。浏览器最终是否保存到磁盘不可由服务器验证，记录表示已成功生成并开始下载。

## 2. 当前分配信息维护

- 正常审批与手工补录的当前有效分配均可维护。仅原本使用资源编码的资产允许修改编码，沿用有效分配全局唯一约束，不得把必填编码清空；原申请快照不篡改，当前列表/检索/导出与释放快照使用当前编码，审计保留前后值。
- 交换机 IP 与端口号在审批、补录、编辑中分为同一行两个输入框，均选填。交换机 IP 使用 IPv4；端口仍是字符串，可填写 `36`、`GE0/0/1`、`Eth-Trunk1` 等。明确的旧 `IPv4-端口` 可拆分回显，其余原文保留为端口，不猜测 IP。
- 所有 MAC 入口取消位数、十六进制、分隔符与大小写规则，不自动转换格式，保留录入文本；选填，可清空。容量为 256 个字符，拒绝控制字符，页面与服务端一致。
- 设备序列号选填，最多 100 个字符，不要求唯一，仅管理员填写、修改、查看与导出；审批、补录、后续维护、管理员详情、导出和释放历史均覆盖。
- 维护使用分配 ID、IP ID 与预期版本，旧页面不得覆盖新分配或其他管理员的新修改。实际变化写审计，释放后当前池不残留上次设备信息，再分配不继承旧值。

## 3. 批量已占用

- 资源池首列复选框和当前页全选只选择可用 IP，显示选择数量，经系统对话框确认批量标记为“已占用”。服务端重新校验全部目标，任一不再可用则整批不写入。
- “已占用”表示现实中已使用、资料待补录，与已有完整分配关系的“已分配”分别显示。不得伪造申请或空壳分配。
- 已占用立即退出审批候选、可用数，并计入占用统计；允许后续逐条补录资产及必要信息，完成后成为已分配；这类分配释放后恢复可用。
- 管理员可将误标的已占用恢复可用；已分配、当前网关和其他非可用状态不能被批量标记。保留操作人、时间及状态变更审计。

## 4. PING 和重点界面

- 资源池与审批候选四种检测状态统一中文：连通、不通（无响应）、检测超时、检测失败，并显示耗时。
- 重点整理资源池、审批、补录与分配编辑弹窗。去除重复 MAC 摘要，IP/状态避免逐字断行，列宽、按钮尺寸、表单间距与筛选操作对齐。
- 分配字段集中维护，详情/PING/补录等主动作清晰；释放等次要动作进入更多操作并确认。保留其他页面的现有功能、原生 ES5 与 IE11/奇安信兼容。
- 页面设计使用 Awesome Design 技能；实际浏览器覆盖常用桌面与较窄屏宽，不以源码字符串检查替代交互验收。

## 5. 验收与交付

- 测试使用隔离库；覆盖管理员/科技管理员权限、V021 历史库升级、分配信息前后值、唯一性、并发版本、释放/重新分配、CSV/XLSX、批量原子性、统计互斥、备份文件校验及恢复/失败回滚/重登录。
- 保留原有阶段回归并更新与本轮新规则直接冲突的旧预期，不能删掉故障分支来使测试通过。
- 新增可在 macOS/Linux 执行的 Java 11 构建与回归入口，保留 Windows 发布线；生成自包含麒麟 ARM64 离线 ZIP，核对版本、迁移、文件路径和全部文件摘要。
- 每个修复的根因、解决方法和防回归记录到项目 memory.md。开发机通过不代表麒麟或 IE11/生产实机验收。
