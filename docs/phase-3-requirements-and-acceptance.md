# 第三阶段需求与验收基线

版本：2026-09-03；基线：`ea424d9`。

本阶段实现科技管理员本人已分配 IP 的二次确认后立即释放、管理员站内通知与释放历史、资源统计、CSV/XLSX 导出和离线交付。释放不经过审批、不设倒计时、不做 Ping、定时扫描、异常队列、撤销恢复、邮件或短信。

## 不可变业务规则

- 仅记录所有人且状态为 `ASSIGNED` 的科技管理员可释放；成功后永久为 `RELEASED`。
- 释放、解除 IP/资源编码占用、释放事件、审计和管理员通知在一个 SQLite 短写事务内完成。重复或并发请求仅一次成功。
- 通知仅发送给启用且未软删除的管理员；通知可标记已读并进入释放历史。
- 已释放 IP 与科技资产资源编码可在新申请中重新使用，原申请、分配、事件和审计永久保留。
- 统计不计软删除资源；可分配容量为当前可用加当前已分配，分母为零时使用率为 0%。
- 导出字段由固定白名单控制，CSV 使用 UTF-8 BOM，XLSX 不生成公式、宏或外部链接；以 `= + - @` 开头的数据加单引号防止公式注入。

## 3.1 补充需求

- 业务“网点”列表可按所属支行、启用状态及编号/名称筛选，不改变既有网点、地址段与审批的关系。
- 地址段绑定采用两级选择：先选支行，再只展示该支行内可绑定的网点；后端仍以网点归属关系作最终校验。
- 新增独立、仅展示用途的“网点信息”资料库，字段为管理网点号、网点号、机构编码、网点名称、网点地址、电话、所属支行。它不参与 IP 申请、地址段绑定和资源分配；支持筛选、逐条编辑和 `.xlsx` 原子导入。
- 导出页按数据类型显示可导出字段，至少勾选一项；服务端继续以字段白名单决定实际可导出字段。

## 验收门

自动化验收需先跑第一、二阶段回归，再覆盖 V006 升级、V008 资料库升级、所有权、幂等与并发释放、事务原子性、通知收件人过滤、统计口径、导出字段白名单/注入防护和越权。浏览器验收需覆盖网点筛选、地址段两级选择、网点信息 XLSX 上传与编辑、确认弹窗、释放后状态、通知/历史、统计、两种下载、空/加载/失败状态和 760px 窄屏；本地结果不能替代麒麟 ARM64 或 IE11/奇安信实机证据。
