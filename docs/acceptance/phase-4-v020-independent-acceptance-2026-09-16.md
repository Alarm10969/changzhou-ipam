## 待修复问题

1. **P2 · 管理员无法在系统内查询端口修改前后值。** `audit_log.detail_json` 已保存如 `{"before":"Gi0/0/2","after":"Gi0/0/3"}`；但 `GET /api/v1/admin/audit` 的查询未返回 `detail_json`（`backend/src/main/java/com/icbc/changzhou/ipam/IpamApplication.java:172`），审计页面仅显示时间、操作人、动作和对象（`frontend/app.js:964-975`）。复现：管理员修改端口后打开“审计日志”，只能看到 `UPDATE_SWITCH_PORT / IP_ASSIGNMENT`，无法看到前后值。与基线第 31、45 行的“审计能查到前后值与操作者”不符。建议仅针对授权管理员提供安全的端口修改详情展示；不要把其他审计中的口令等敏感内容原样输出。
2. **P3 · 端口保存成功缺少明确反馈。** 编辑端口成功后弹窗关闭并刷新列表，但没有“保存成功”提示（`frontend/app.js:1171`），与基线第 39 行的反馈要求不完全一致。建议增加简短成功提示，失败提示保留现状。
3. **P3 · 旧弱口令强制改密的 API 原因文案不准确。** 旧弱口令用户访问业务 API 时收到“该账号必须先修改初始或重置后的密码”（`backend/src/main/java/com/icbc/changzhou/ipam/IpamApplication.java:73`），但该用户并非初始或重置口令。建议使用兼容三种触发原因的通用描述，例如“请先修改密码后继续使用业务功能”。
