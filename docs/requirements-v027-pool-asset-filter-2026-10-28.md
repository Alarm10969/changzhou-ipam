# V027：IP 资源池资产两级筛选

用户于 2026-10-28 确认增加资产大类和资产小类联动筛选。

- 入口：基础资料 → IP 资源池，现有筛选区。
- 资产大类：全部资产大类、科技资产、非科技资产。
- 资产小类（资产名称）：系统资产定义及当前有效分配的资产快照。可在大类为“全部”时直接选小类；跨大类同名资产按定义 ID 区分。选择大类后只显示该大类对应选项，切换大类清空小类。
- 已停用资产仍可查询其在用分配。已删除、改名或改类资产若存在有效分配，保留相应快照选项；大类为“全部”时，同一资产 ID 的名称和大类合并显示，避免相同 value 的重复选项。
- 新增配置自动进入选项；没有资产定义时仍可使用原有筛选。
- 查询只读取当前 `ASSIGNED` 分配。审批使用申请资产快照；单条和批量补录使用手工资产快照。资产配置后续修改不改变已有分配归类；释放历史不参与筛选。
- 无资产归属的 IP 仅在资产条件均为“全部”时显示。与支行、网点、网段类型、地址状态、关键词共同满足；互斥条件返回空结果。
- 过滤在数据库执行，列表与总数共用条件。翻页保留条件，改变条件回到第 1 页，重置清空全部条件；筛选与翻页清空当前页勾选，延迟返回的旧查询不覆盖新查询。
- 页面使用原生 ES5 控件和现有样式，桌面筛选分行、较窄屏幕两列，表格保留自身横向滚动。

管理员接口：

- `GET /api/v1/admin/ip-pool-v2` 新增可选 `assetType=TECH|NON_TECH` 与正整数 `assetId`，与既有参数组合。
- `GET /api/v1/admin/ip-pool-asset-options` 返回配置与有效分配快照的选项。科技管理员和未登录用户不能调用。
- 错误类型或非法编号返回 400；不存在的正整数编号返回空列表。

无新增数据库迁移，schema 仍为 V001–V023。V026 批量补录功能随本版保留。
