# 第四阶段人工验收清单

版本：`3.5.0-v020-password-switch-port`，数据迁移：`V019`。

## 账号与密码

1. 以管理员创建账号、重置账号密码，分别输入缺少长度、大写、小写、数字的样例，确认表单即时显示具体缺项，服务端再次拒绝不合规值。
2. 以历史弱密码账号登录，确认只显示改密页面；访问业务接口返回 `PASSWORD_CHANGE_REQUIRED`，`auth/me`、退出和改密仍可用。
3. 用符合规则的新密码完成改密，确认业务导航恢复；确认旧会话失效。
4. 确认特殊字符不是必填项，8–72 位且含 ASCII 大写、小写和数字即可通过。

## 交换机端口

1. 管理员审批申请时，在选定 IP 下方填写端口，确认选中的 IP、网段和端口同时出现在确认摘要中。
2. 在端口框输入超过 64 个字符或换行/控制字符，确认即时提示具体错误，已选 IP 不丢失。
3. 审批后在 IP 资源池确认当前端口，使用“编辑端口”单独修改和清空；确认不会改变 IP 状态。
4. 打开两个管理员页面，用旧分配版本保存第二次修改，确认服务端返回冲突并要求刷新。
5. 释放 IP 后检查释放记录仍保留原端口；再次分配同一 IP 时填写新端口，确认两次分配互不覆盖。
6. 检查审计日志包含操作人、分配记录、修改前值和修改后值；同值保存不新增审计记录。

## 角色、导出与窄屏

1. 管理员在 IP 池、申请明细和释放记录查看端口，并在池、申请、分配、释放四类导出中勾选端口。
2. 科技管理员检查申请、我的 IP、通知和可访问接口，确认不返回、不展示端口；尝试管理端端口接口应被拒绝。
3. 在 640px 左右宽度完成审批和 IP 池端口编辑，确认页面无横向溢出，错误提示和焦点可见。
