# V030 本行版升级说明

部署包以 ipam-stage4-v030-ipv6-kylin-arm64- 开头。请将包复制到本行原安装目录，在该目录解压指定的本次 ZIP 后运行 sh ./deploy/install-stage3.sh。保留原 ipam.conf 和数据目录。安装脚本校验发布文件、停止脚本管理的旧进程并备份数据库，再启动服务。此次数据库结构沿用 V023。

进入“实用工具 → IP地址计算器”，选择 IPv6，可输入地址/前缀、查看准确地址范围和数量。进入“基础资料 → 地址规划 → 现有地址段”，支持按支行、网点、类型和 CIDR 或网关分页查询，可选每页 20、50 或 100 条。
