# V022 手工测试步骤

## 管理员：补录已分配

1. 登录管理员账号，进入“IP 资源池”，筛选一个 `可用` 地址，点击“补录已分配”。确认 IP、支行、网点、CIDR 和原状态为只读。
2. 分别选择仅资源编码、仅使用人、两者都要、两者都不要的启用资产定义。确认表单只显示定义要求的字段；填写错误时表单保持打开并保留已填内容。
3. 填写或不填写负责科技管理员、端口和说明。先点击“查看并确认补录”，核对摘要后再确认写入。
4. 验证资源池变为“已分配”，申请列表没有新增虚构申请；详情显示来源、登记人、登记时间和责任人。
5. 对停用、人工保留地址各做一次补录，管理员释放后分别确认恢复为停用、人工保留；对当前网关和已分配地址确认服务端拒绝。
6. 指定责任科技管理员后，以该科技管理员登录，确认“我的 IP”可见且可释放；不指定责任人时确认科技管理员不可见。确认科技管理员页面、通知和接口响应不出现交换机端口。

## 管理员：调整网关

1. 在当前网关行点击“调整网关”，确认网关操作与“编辑状态”分开，候选只来自同一地址段的已有主机。
2. 分别选择原本可用、停用、人工保留的目标，确认旧网关变为可用、目标变为系统保留；检查页面成功提示和审计记录。
3. 重复选择当前网关，确认幂等返回且不新增审计；选择跨段、网络地址、广播地址或已分配目标，确认拒绝且旧网关和目标状态均未改变。
4. 按页面警告核对真实路由器、DHCP 和网关配置；系统不会替用户修改外部网络设备。

- 运行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\package-kylin.ps1`，逐文件核对 ZIP 清单、SHA-256、V020 迁移、版本文件和安装脚本。
- 目标机先备份 `data/ipam.db`，再按 README 的单条安装命令升级；完成后做健康接口、管理员权限、迁移版本和上述手工步骤复测。
