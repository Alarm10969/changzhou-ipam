# 常州 IP 资源审批分配管理系统

## 第三阶段需求变更基线发布说明（2026-09-04）

本发布以 `requirements-change-baseline-2026-09-04.md` 为准，保留第二阶段与既有第三阶段不冲突能力。

### 本次交付

- 固定全局地址范围 `108.56.0.0/13`，按当前规则为每个网点一次性、原子生成生产、网络管理、扩展、监控、测试、办公六个 `/24` 及地址池；默认偏移为 `0/3/11/12/13/15`。
- 地址规划支持单网点预览确认，以及 Excel/CSV 模板批量上传、逐行六段预览和整批原子确认；旧一对一地址段不会自动推测迁移。
- 设置中展示生效规划版本、DNS、六类网段和资产小类到网段映射；未映射或网点六段不完整时禁止申请。
- 申请按支行、网点、资产类型、小类逐步填写；PC 使用人信息与科技非 PC 资源编码按规则校验，申请人由当前科技管理员自动记录。
- 资源池支持支行、网点、网段类型和 IP/使用人/统一认证号/资源编码查询、分页、详情、受控 PING、状态编辑与管理员强制释放。
- 审批记录保留推荐/最终网段、改选原因、审批意见和使用人/资源信息；导出支持字段选择。

### 已知边界

- 科技资产正式分类表尚未提供：系统只提供可配置框架及 PC 特殊规则，未编造科技小类。
- 开发机回归已通过；麒麟 V10 SP1 ARM64 与 IE11/奇安信实机验收仍需在目标环境执行。
- PING 为受控诊断，不会改变 IP 状态、释放资源或触发倒计时。

### 页面设计记录

本轮依据 Awesome Design 的信息层级建议，把地址规划分为单笔生成、低频批量导入、现有列表三个层次；申请表按前置选择渐进显示条件字段；资源池保持主表加详情弹窗和可见的禁用/加载/失败反馈；既有 760px 窄屏堆叠规则继续覆盖筛选与操作区。
