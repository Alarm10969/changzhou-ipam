# 第二阶段易用性手工测试清单

1. 使用新建账号或被重置密码的账号登录，确认只显示“概览与密码”和退出；直接触发业务请求时提示先改密，列表不会卡在加载中。
2. 完成改密，确认对应角色完整导航立即恢复；旧会话刷新后回到登录页并显示“登录状态已失效，请重新登录”。
3. 管理员首页核对支行数、网点数、未绑定网点数、可用 IP 数、待审批数及四步快捷入口。
4. 创建支行、网点并绑定 `/24` 地址段，确认资源池自动产生 254 个主机地址；网关为只读系统保留，其余默认可用。
5. 单独把普通 IP 改为停用、人工保留和可用；人工保留不填原因应被拦截。勾选多个普通 IP 批量修改，混入系统保留或已分配 IP 时整批不得写入。
6. 编辑支行、网点、地址段，核对保存前影响范围；制造有效分配后尝试停用或破坏关联，应显示明确原因并拒绝。
7. 科技管理员提交申请，连续点击提交按钮时只能生成一笔；“我的申请”显示清晰进度。驳回后显示原因和下一步。
8. 管理员按支行、网点、申请人或资产编码筛选；确认列表最早提交优先并显示等待时长。
9. 选择可用 IP，核对申请摘要、总数和页数、整行选择高亮、不默认选中，以及最终分配确认摘要；确认可选 IP 只来自申请网点。
10. 审批通过后，在“我的申请”复制 IP、掩码、网关和 DNS。
11. 在网点、地址段、IP 资源池页面分别下载模板并上传：核对文件名、成功/失败统计、错误表、错误报告下载、最近记录；任一行错误时确认按钮不可用且业务表无写入。
12. 按 Esc 关闭弹窗，以 Tab/Shift+Tab 检查焦点不离开弹窗，关闭后焦点回到原按钮。
13. 在地址段页保存默认主 DNS 和备 DNS；重新进入页面确认仍保留，新建地址段确认自动带入；用 DNS 空单元格的模板预览并确认，核对导入地址段采用默认值且已有地址段未变化。
14. 在支行和网点列表打开删除弹窗，核对对象名称、网点/地址段/IP/待审批/历史分配数量；删除网点后确认其地址段和地址池不再出现，待审批申请自动驳回，已审批历史仍可查看。
15. 删除含多个网点的支行，确认所有下属网点、地址段和地址池从业务列表消失，审计日志出现 `DELETE_BRANCH_CASCADE`；刷新首页统计应同步减少。
16. 审批页核对筛选字段与“查询申请/重置条件”在宽屏同一行且底部对齐；窄屏下字段和按钮应依次整行显示，不得重叠或横向溢出。
