# 升级、备份与回滚

## 安装或升级

把新 ZIP 放入已存在的 `/data/项目/IP管理系统`，在该目录解压并执行 `deploy/install-stage2.sh`。脚本会校验发布文件与离线依赖；如发现脚本管理的旧进程会先正常停止；如已有 `data/ipam.db`，会在 `data/backups/` 创建带时间戳的升级前在线备份；随后执行麒麟 ARM64/Java 11 门禁并启动应用。

安装脚本不会删除或重建现有数据库。首次启动仍会交互读取管理员账号和密码；已有管理员时该口令不会覆盖数据库账号。

## 回滚

记录安装输出中的升级前备份绝对路径，并保留上一版本 ZIP。回滚时执行：

```sh
cd '/data/项目/IP管理系统'
sh './deploy/rollback-stage2.sh' '/data/项目/IP管理系统/data/backups/实际备份文件.db' '/data/项目/IP管理系统/上一版本.zip'
```

脚本会停止由本项目 PID 文件记录的进程，校验备份后恢复数据库，并在数据库旁保留当前库的 `.before-restore` 回滚副本；提供旧版本 ZIP 时同时恢复程序文件。完成后按旧版本说明重新启动。

若服务不是由本包启动脚本管理，脚本不会猜测或强杀进程；请先由运维确认并停止对应 Java PID。
