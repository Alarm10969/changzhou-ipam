# V025 资源维护与备份恢复

版本：`3.9.0-v025-resource-maintenance`，数据库最高迁移 V022。已发布迁移保持原校验和，V021 旧库原地增加字段，不删除历史业务数据。

本版新增管理员完整数据备份下载、全系统七天非强制提醒和网页全量恢复；恢复前自动保存原库、失败回滚，成功后全部旧会话失效。管理员统一维护当前分配资源编码、交换机 IP/端口、自由文本 MAC、可选设备序列号；原资产关联规则、有效编码唯一性及管理员字段权限继续生效。

资源池支持勾选当前页空闲 IP 批量标记“已占用”，立即退出审批候选；后续补录为已分配，误标可恢复可用。PING 四种结果中文化，重点整理资源池及审批、补录、编辑弹窗的摘要、列宽和操作布局。

安装前保留完整数据库备份。升级后如需程序降级，不能将 V022 数据库直接交给旧程序，应使用升级前的 V021 快照并按既有停服回滚流程恢复。网页恢复支持 V021 和当前 V022 的完整数据库备份；更早备份须另行走运维升级路径，避免旧演示数据重置迁移。

完整规则见 `requirements-v025-2026-10-09.md`，逐项人工验收见 `stage4-v025-resource-maintenance-manual-test.md`。构建与回归结果在本轮验收记录中列明；未进行目标环境实机检查时不能宣称生产验收通过。
