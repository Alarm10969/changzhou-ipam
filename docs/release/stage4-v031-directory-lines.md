# V031 本行版双线资料维护

版本为 3.15.0-v031-directory-lines。进入基础资料中的网点信息，可维护两条专线的运营商、带宽、月费和网点统一的扁平化状态。两条月费均填写时显示合计，未填保持待补充。

上传入口提供完整模板和专线补充模板。沿用旧模板列名，新增 flat_status、line1_carrier、line1_bandwidth、line1_fee、line2_carrier、line2_bandwidth、line2_fee。模板内有填写说明。月费单位元，最多两位小数。支持动态带宽。

按所属支行编码和网点号匹配已有记录。新记录要求机构编码、名称完整。更新的空白单元格保留原值，页面编辑可清空。上传后逐行预览新增、更新、错误和前后差异，全部通过后确认整批写入。预览有效期30分钟，资料发生变化后须重新预览。同一任务重复确认返回原结果。

部署前保存完整备份。在原安装目录解压本行版部署包，运行 sh ./deploy/install-stage3.sh。脚本按原配置停止受管理进程、备份并升级。新增数据库迁移 V024，自动添加专线字段和导入任务表。已有网点信息保留。完整备份包含新资料，恢复会使未确认的网点资料预览失效。

原始 .et 表请整理到系统下载的 .xlsx 模板后上传。系统使用支行编码和网点号定位，名称不能替代匹配标识。
