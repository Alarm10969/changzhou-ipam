# 第三阶段手工测试清单

1. 科技管理员打开“我的 IP”，检查使用中、已释放两类状态。
2. 打开释放确认弹窗，核对 IP、组织、资产、资源编码、分配时间和不可撤销说明；确认后按钮消失。
3. 管理员在“站内通知”查看通知、标记已读并进入“释放记录”；检查筛选。
4. 重新提交申请并确认已释放 IP 可以选择；资源概览数字与表格一致。
5. 下载 CSV 与 XLSX，验证 CSV UTF-8 BOM、无公式执行、字段与范围正确。
6. 在 760px 窄屏检查导航、表格和弹窗；检查浏览器控制台无错误。
7. 管理员在“网点”使用支行、状态和关键字筛选；确认结果数与列表一致。
8. 在“地址段”先选择支行，确认“绑定网点”只出现该支行的未绑定网点；编辑时也应同样级联。
9. 在“网点信息”下载模板、上传有效 `.xlsx`、按关键字筛选并编辑一条记录；确认模板和页面均不含“管理网点号”，且它未出现在 IP 申请的网点选项中。
10. 在“数据导出”取消部分字段后下载 CSV/XLSX，确认文件只含勾选字段。
11. 在“IP 资源池”直接用 IP、已分配人员姓名及统一认证号分别全局检索；再按支行、网点缩小范围。确认选中网点后地址段仅自动展示、不可再次选择，且结果展示支行、网点、地址段、姓名和认证号，并验证首页、末页与页码跳转。
12. 对一个已分配 IP 使用“强制释放”，确认必须填写原因、释放记录审计动作为 `ADMIN_FORCE_RELEASE_IP`；对一条待审批申请选择 IP 后，确认分配前显示自动 Ping 的结果或风险提示。
13. 验证网点、网点信息列表每页最多 20 条且能跳转；验证地址段列表可按支行、状态和 CIDR/网点名称筛选。
14. 管理员审批一条推荐为“办公”的申请：保持“办公”时不显示改选原因；改选“测试”时必须出现并填写改选原因。确认缺少原因不能提交；填写原因后成功分配，并在申请详情、审计日志和导出勾选字段中都能看到该原因。
15. 在审批弹窗中依次验证第 1 页→第 2 页、输入页码跳转末页、上一页和下一页；在第 2 页选择 IP 后翻到其他页再返回，选择与确认摘要必须保留。点击一条 PING 后仍可翻页；切换最终网段后必须清空选择，且不能出现 `ip-pool/null/reachability` 请求。

未实机验证：麒麟 ARM64、IE11/奇安信兼容模式以及真实第二阶段业务库升级演练。
