# 第三阶段 V013 验收整改补充

适用版本：`3.3.0-six-network-baseline`，数据库迁移升级至 V013。

## 已修复

- 科技资产 PC 申请不再要求资源编码；必须填写 PC 使用人姓名和统一认证号。科技非 PC 仍必须填写资源编码。
- 申请详情始终保留实际分配 IP；IP 被释放后仍显示该 IP、分配时间和释放时间。
- 资源池“编辑状态”打开时回显当前可编辑状态；已分配和系统保留地址明确不可编辑。
- 申请详情为只读，只提供关闭操作；审批或驳回成功后，左侧待审批角标即时刷新。

## 升级与验证

启动时自动执行 V013。该迁移重建 `ip_application` 的旧 CHECK 约束，保留所有申请主键及与分配、通知、释放事件的关联；迁移后执行 SQLite `foreign_key_check`，失败即阻止服务正常启动。

建议在升级后执行：

1. 用科技管理员提交一条 PC 申请（只填姓名和统一认证号，不填资源编码），确认返回待审批而非系统错误。
2. 审批、释放该申请后，在“申请审批 → 已通过 → 详情”确认原始 IP 和释放时间仍可见，且没有“保存修改”按钮。
3. 在资源池把一个可用 IP 设为人工保留，筛选“人工保留”并再次编辑，确认下拉框仍选中“人工保留”。
