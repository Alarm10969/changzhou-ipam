# V024 账号重建登录修复发布说明

版本：`3.8.2-v024-account-login`

目标：麒麟 ARM64 / Java 11

数据库结构：不新增迁移，兼容当前 V021 数据库

## 修复内容

- 修复账号因角色选错而被软删除、随后用相同登录名按正确角色重建后无法登录的问题。登录现在只查询未删除账号；旧账号行、内部 ID、历史申请和审计关联均保留。
- 继续允许同一登录名被新账号复用，同时仍由数据库唯一约束阻止同名的第二个未删除账号。
- 管理员重置密码时清除连续失败次数和锁定时间；账号仍要求在下次登录后修改密码。
- 删除确认提示说明同名重建规则和历史保留方式。

## 验证

- `StageEightBranchUserReuseSmokeTest` 覆盖旧科技管理员删除、同名创建管理员、新密码登录、旧密码拒绝、重置解除锁定和同名活动账号拒绝。
- 阶段 1–13 后端回归及两个浏览器回归通过；包含历史数据库升级、Edge 页面窄屏和账号删除确认文案验证。
- 完成 Java 11 编译、前端语法检查、差异空白检查和发布包校验。

麒麟 ARM64 原生启动、IE11/奇安信兼容性和生产环境部署仍需在目标环境执行；本地回归不代表这些现场验收已完成。

## 升级与回滚

本版本不修改数据库结构。包内安装脚本仍会在升级前备份数据库、核对版本与依赖、执行麒麟 ARM64 预检并进行健康检查。若需回滚，可按现有流程恢复 V023 应用文件；由于没有新增数据迁移，无需为本版本单独回退数据库结构。回滚会重新暴露 V023 的同名重建登录缺陷。
