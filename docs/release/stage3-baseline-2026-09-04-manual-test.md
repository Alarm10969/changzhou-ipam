# 第三阶段需求变更基线手工验收清单

## 1. 地址规划

1. 管理员进入“地址规划”，选择支行、网点，填入对齐的生产 `/24`，点击“预览六类网段”。
2. 确认显示生产、网络管理、扩展、监控、测试、办公六段和网关；确认生成后列表显示六种类型，地址池每段均已创建。
3. 下载 Excel/CSV 模板，上传有效多行数据，核对每行展开的六段预览，再确认整批生成。
4. 上传重复网点、已规划网点、重叠 CIDR、未启用支行/网点和非对齐 CIDR，确认没有写入任何一行。

## 2. 申请与审批

1. 科技管理员依次选择支行、网点、资产类型和小类；核对 PC 只显示姓名/统一认证号，科技非 PC 只显示资源编码，非科技不显示这三项。
2. 对未映射小类和缺少六段的网点提交，确认后端拒绝且提示原因。
3. 管理员审批时核对推荐网段及候选 IP 均属于同一网点；尝试改选其他网段，确认没有填写原因时被拒绝。
4. 打开已审批申请详情，核对申请、审批、分配、使用人/资源信息完整。

## 3. 资源池、PING 与导出

1. 用支行、网点、网段类型以及 IP、姓名、统一认证号、资源编码分别查询；核对分页和跳页。
2. 点击可编辑 IP 的“编辑状态”，确认弹窗带入当前值并能保存；已分配和系统保留 IP 必须显示不可编辑原因，已分配项保留强制释放入口。
3. 点击逐行 PING，确认有加载和结果反馈；重复点击受限，结果不改变 IP 状态，也不产生释放记录。
4. 导出时仅勾选部分字段并分别导出 CSV/XLSX，核对表头、筛选结果和数据不含未勾选字段。

## 4. 兼容性

1. 在 760px 以下核对筛选、按钮和弹窗仍可完成操作。
2. 在麒麟 V10 SP1 ARM64、Java 11 运行安装和校验脚本；在 IE11/奇安信浏览器重复本清单第 2、3 节。
