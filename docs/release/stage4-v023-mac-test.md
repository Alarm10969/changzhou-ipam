# V023 MAC 地址人工验收清单

以下项目由管理员账号执行；科技管理员账号只用于验证隔离。

- [ ] 登录后确认页头显示 `3.8.1 · V023`。
- [ ] 审批确认填写 `AA:BB:CC:DD:EE:FF`、`AA-BB-CC-DD-EE-FF` 和 `AABBCCDDEEFF`，确认摘要可见，保存后均显示为大写冒号格式。
- [ ] 审批确认填写内部空格、混合分隔符、EUI-64、非法十六进制和错误组数；表单保留，提示 MAC 格式错误。
- [ ] “补录已分配”填写 MAC，二次确认摘要同时显示端口、MAC 和补录说明；保存后资源池当前摘要可见。
- [ ] 同一 MAC 可出现在两个有效分配中；不应被唯一性校验拦截。
- [ ] 在当前有效分配上分别修改 MAC、再次保存相同规范化值、清空 MAC；成功后当前行/详情刷新，修改记录出现在审计中，相同值不新增审计。
- [ ] 用两个管理员页面打开同一分配，先保存一个页面，再用旧版本保存另一个页面；后者返回冲突并要求刷新。
- [ ] 释放带 MAC 的分配，在释放历史看到 MAC 快照；同一 IP 重新分配后当前 MAC 显示 `—`。
- [ ] 管理员资源池、审批历史、当前详情、释放历史可见 MAC；表格窄屏不出现横向溢出。
- [ ] 导出 POOL/APPLICATION/ASSIGNMENT/RELEASE：选择 MAC 时 CSV/XLSX 含 `MAC 地址`，取消选择时不含该列；释放导出保留历史 MAC。
- [ ] 科技管理员申请、本人 IP、通知和所有页面不显示 MAC；直接调用管理员 MAC 编辑/导出接口返回 403。
- [ ] 备份数据库后执行升级；确认既有分配和释放记录保留、旧记录 MAC 为 `NULL`；模拟恢复备份可回到 V022。

自动回归入口：`scripts/test-stage4.ps1`。当前已在 Windows 隔离数据库和 Edge 真实浏览器执行；麒麟 ARM64、IE11 和生产数据库仍需独立验收。
