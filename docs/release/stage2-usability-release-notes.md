# 第二阶段易用性修订说明

版本：2.1.0-usability

## 本次变更

- 首次登录或管理员重置密码后，仅开放“概览与密码”和退出；改密成功后按角色恢复完整导航。
- 统一处理会话失效、必须改密、业务校验和网络错误，失败后不再停留在“加载中”。
- 新增支行、网点、地址段、资源池检查向导和待审批统计。
- IP 统一显示为可用、停用、人工保留、系统保留、已分配五种互斥状态；支持普通未分配 IP 的原子批量调整。
- 用系统内弹窗替换浏览器原生提示框，补充对象影响、字段校验、键盘焦点和确认摘要。
- 审批支持支行、网点和关键字筛选，按最早提交优先；手动选 IP 保持搜索、分页、单选且不默认选择。
- 批量导入继续位于原业务页面，增加文件名、预览统计、错误报告和最近导入记录。
- 基础资料编辑显示影响范围；存在有效分配时禁止停用或破坏地址段、网点关联。
- 审批筛选区改为紧凑工具栏，查询与重置按钮和字段在宽屏底线对齐，小屏整行显示。
- 支行和网点支持级联软删除；下属地址段、地址池同步停用并隐藏，待审批申请自动驳回，历史分配与审计记录保留。
- 地址段页新增默认主 DNS、备 DNS 系统参数；新建地址段自动预填，批量导入空 DNS 自动使用默认值，已有地址段不被改写。
- README 补充 SQLite、导入暂存文件、备份、日志、PID 和运行环境参数的准确存储位置。

## 兼容与边界

- 继续使用原生 ES5 前端和 Java 11，不引入 Node、前端框架、Maven、Nginx 或 MySQL 运行时依赖。
- 数据库升级到 V001-V006；V006 只增加软删除字段、索引和默认 DNS 配置项。应用启动会校验迁移摘要并自动补齐未执行迁移，不会重建现有数据库。
- 开发机回归不等于麒麟 ARM64、IE11/奇安信兼容模式或真实旧库升级实机验收。
