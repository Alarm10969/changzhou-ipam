# V025 手工验收

本轮需求已由用户于 2026-10-09 确认。测试应使用隔离数据；生产恢复由管理员在页面明确确认，开发验证不操作真实业务库。

1. 分别登录初始管理员和其他管理员，均能进入备份与恢复；科技管理员无入口，直接调用接口返回 403。下载 ZIP 可保存到当前操作电脑，页面更新全系统最近备份时间和操作人。另一管理员登录读取相同时间；超过七天显示提醒，可以关闭并正常继续操作。
2. 上传刚下载的备份，预览显示时间、数据版本和数量，明确覆盖账号、密码、权限、设置及所有业务数据。取消不会替换数据库；损坏文件、不同系统、未来版本或校验不符明确拒绝。
3. 在隔离库备份后修改一项数据，再上传原备份并确认恢复；恢复前生成当前库回滚备份。恢复期间其他会话的业务请求明确暂停，完成后旧会话失效，使用备份时的账号密码重新登录，数据与备份一致。
4. 服务测试覆盖恢复前校验失败与恢复中失败回滚；原数据必须保留。模拟替换后进程中断，启动先按恢复标记回滚或确认完成。V021 原备份只在副本升级到 V022，不修改源文件。
5. 对正常审批和手工补录产生的当前分配，编辑资源编码，列表、搜索、导出和后续释放历史显示新值；原申请快照和审计可追溯。重复有效编码、过期分配版本、已释放记录拒绝修改。不关联编码的资产没有编码修改入口。
6. 审批、补录、编辑均在同一行分别填写交换机 IP 与端口；例如 `108.56.195.250` 和 `36`，端口可填写 `GE0/0/1`。旧 `IPv4-端口` 正确拆分，只有端口的旧记录保持完整。选填、清空和错误后保留输入都可用。
7. 所有 MAC 输入允许普通文字、不同分隔符、内部空格和大小写，保存后保持录入内容，不自动转格式。序列号选填、可修改/清空，管理员详情、导出、释放历史一致；科技管理员页面及其 API 不包含序列号、MAC、交换机字段。
8. 资源池勾选当前页可用地址，显示数量并确认批量已占用；非可用、已分配、网关不可勾选。并发导致任一地址状态变化时整批拒绝，不部分写入。
9. 已占用从审批候选和可用数量消失，单独计入占用统计；完整 IP 和占用状态筛选可查询。误标恢复可用；补录真实资产后成为已分配，不多出虚假申请，该分配释放后恢复可用。
10. 资源池与审批候选 PING 返回四种中文结果；翻页、筛选、PING 后事件仍正常。资源池 MAC 摘要不重复，IP 与状态不逐字断行，主要操作和更多操作可用；审批和补录表单对齐。
11. 在常用桌面与较窄屏宽检查表格、筛选、弹窗、交换机同行输入和备份页面，页面控制台无异常。开发机 Edge 结果不得代替麒麟 ARM64、IE11/奇安信的实机验收。

升级安装沿用已有目录：先备份，复制 V025 ZIP，解压后执行 `sh deploy/install-stage3.sh`；版本文件及安装校验必须均为 `3.9.0-v025-resource-maintenance`，数据库最高迁移为 V022。
