# V026：批量补录已分配

版本：`3.10.0-v026-assignment-import`。数据库迁移：V001–V023。日期：2026-10-28。

## 使用入口

管理员登录后进入“基础资料 → IP 资源池”，在地址列表右侧点击“批量补录已分配”。无需选择当前页的 IP。

1. 下载 CSV 或 XLSX 模板，每行填写一个实际使用的 IP。IP、资产类型、资产名称必填；资产和 IP 必须已在系统中存在。使用人和资源编码按资产定义填写，不需要的字段留空。
2. 上传并预览，核对通过、重复、错误数量及逐行结果；可展开查看原表全部资料。
3. 点击“确认导入通过行（N条）”。只导入通过行，重复跳过，冲突不覆盖。没有通过行时不能确认。
4. 下载未通过/未导入 CSV，修正后重新上传；原有批次保留在最近导入记录中。

文件限 UTF-8 CSV、无宏无公式 XLSX，最多5 MiB、2000条非空数据。表头沿用统一模板14列；XLSX“导入数据”页与说明页分开。原来的 XLS 须另存为 XLSX 后按统一模板整理。

如果预览期间 IP 状态、分配信息、资产规则或责任账号发生变化，确认时先刷新预览，所有通过行均不写入，需要按新预览再次确认。通过行写入时如发生数据库异常，全部通过行回滚。已完成任务的再次确认返回原结果。

社保卡原表记载的是连接制卡机的 PC IP，应先确定资产口径；本次升级不会自动导入原始业务表，也不自动新建资产、IP 或修改实际网络设备。

## 升级与回退

将完整的 `ipam-stage4-v026-assignment-import-kylin-arm64-YYYYMMDD-HHmmss.zip` 复制到麒麟既有安装目录，核对传递前后的大小及 SHA-256。只复制原 ZIP，名称以 `._` 开头的辅助文件不是安装包。

```sh
cd '/data/项目/IP管理系统' && unzip -o './ipam-stage4-v026-assignment-import-kylin-arm64-YYYYMMDD-HHmmss.zip' && sh './deploy/install-stage3.sh'
```

把占位文件名换为本次实际发布文件名。安装脚本校验版本和文件摘要、停止本项目旧进程、保留升级前数据库快照，再原地执行连续迁移。V023只增加独立导入任务及明细表，不重建或清空已有业务表。

回退时先停止服务，保留当前完整数据库及备份；恢复升级前V022完整快照并部署对应V025发布包，再启动核对。使用既有 `deploy/backup-restore.sh` 运维流程，不能删除数据库来回退，也不能单独替换 WAL/SHM 文件。

网页恢复支持校验通过的V021–V023完整备份。恢复将撤销会话并使未完成的导入预览失效，恢复后须重新登录和重新上传；已完成任务及分配历史随完整备份保留。

## 验收范围

开发机验证包括Java11编译、阶段1–16、真实HTTP、Edge真实界面与服务器联调、桌面/700宽页面、原有审批/释放/维护/备份回归、发布包内容和摘要。所有写入测试均使用隔离临时库，未操作业务数据库。
