# 第四阶段发布说明

## 版本

`3.5.0-v020-password-switch-port`；目标为麒麟 ARM64 / Java 11；数据库连续迁移至 `V019`。

## 本次变更

- 所有设置密码入口统一使用 8–72 位、ASCII 大写字母、小写字母和数字三项规则，前端即时显示具体缺项。
- 既有账号不被批量改密；弱密码在下一次成功登录后标记为必须改密，改密前服务端阻断业务接口。
- 审批分配记录新增独立的交换机端口快照；端口可选、最多 64 字符，禁止换行和控制字符。
- 管理员可在审批时填写端口，也可针对当前有效分配单独修改或清空；版本条件更新防止旧页面覆盖新值。
- 释放事件保留端口历史；重新分配同一 IP 创建独立分配快照；科技管理员接口和页面不输出端口。
- 池、申请、分配、释放导出提供端口字段，并继续沿用字段白名单和公式注入防护。

## 验证

- `scripts/test-stage4.ps1`：第一至第八阶段回归、第四阶段后端烟测、Edge 真实 DOM/窄屏检查、Node 语法检查和 diff 检查。
- `StageNinePhaseFourSmokeTest`：迁移、密码升级、端口校验、审计、并发版本、释放历史、重新分配隔离、科技管理员隐私和导出白名单。
- `scripts/browser-phase4-regression.js`：审批端口确认、错误时保留选中 IP、资源池端口编辑、640px 页面和科技管理员页面隔离。

## 部署边界

Windows 构建机负责离线编译、依赖校验和 ZIP 制作；本次交付包按麒麟 ARM64 / Java 11 目标打包，但当前开发环境未连接目标麒麟主机，因此 ARM64 原生启动、目标机网络连通性和 IE11/奇安信实机兼容性需现场复核。安装前应保留数据库备份，并使用包内 `deploy/install-stage3.sh` 完成版本、依赖、备份、ARM64 预检和健康检查。
