# V028：IP地址计算器

版本 `3.12.0-v028-ip-calculator`。入口为“实用工具 → IP地址计算器”，管理员和科技管理员修改初始密码后均可使用。

输入IPv4地址（允许附带CIDR），子网掩码、CIDR、连续反掩码任填一种，其他两项自动换算，以最近编辑的输入为准。支持常用前缀按钮、回车计算、重置和复制全部结果。输入变化后清除旧结果；复制不可用时显示可手动选择的文本。

展示网络地址、广播地址、掩码、反掩码、CIDR、主机范围、主机数量、总地址数、输入IP类型、网络/广播地址的无符号十进制整数和完整32位二进制。网络位和主机位使用不同颜色。分类覆盖常见私有、环回、链路本地、共享、文档、测试、组播、保留和协议专用范围，其余标为其他单播地址，不据此判断公网连通性。

/0支持完整IPv4空间的精确计数；/31按点对点链路显示两个端点，无定向广播；/32显示单一主机，无独立广播。数量是子网规则结果，未扣除网关、保留、特殊用途或已经占用的地址，实际空闲情况以IP资源池为准。

计算在浏览器内完成，不请求计算接口，不写入业务数据库，不受资源池108.56.0.0/13范围限制。使用ES5和现有样式，无新增运行时依赖。数据库结构仍为V001–V023，发布包包含V026批量补录和V027资产两级筛选。

规则参考：[RFC 3021](https://www.rfc-editor.org/rfc/rfc3021)、[IANA IPv4特殊用途地址登记](https://www.iana.org/assignments/iana-ipv4-special-registry/)。登记核对日期为2026-11-02，应用运行不访问外网。

验证入口：`node scripts/test-ip-calculator.js`（需Python3标准库ipaddress，858组独立对照）和 `node scripts/browser-ip-calculator-regression.js`（Playwright与Edge）。Windows可用IPAM_PYTHON、IPAM_PLAYWRIGHT、IPAM_EDGE指定已有运行时。开发机测试不替代麒麟ARM64、IE11和奇安信实机验收。
