# 第三阶段变更说明

## 3.0.1 热修

- 修复启动迁移器遗漏 V007，恢复资源统计、释放记录、站内通知及当前版本数据库结构。
- 修复数值型 Excel 支行编号被读为小数而无法匹配的问题。

## 3.1 网点资料与筛选

- 网点列表新增按支行、启用状态、网点编号或名称筛选。
- 地址段绑定改为“先选支行、再选该支行网点”的两级选择，避免几百个网点同列展示。
- 新增独立“网点信息”展示资料库，支持筛选、编辑和 `.xlsx` 原子导入；不影响既有审批网点和 IP 资源逻辑。
- 导出页支持逐项选择字段；后端仍执行固定字段白名单。
- 数据库从 V007 连续增量升级至 V008；安装前自动生成 SQLite 备份，原库不删除。

## 3.1.1 网点资料字段修订

- 删除“管理网点号”字段；其业务含义等同于所属支行号，不再重复存储、展示、筛选或要求 Excel 填写。
- 数据库从 V008 连续迁移至 V009，保留原有网点号、机构编码、名称、地址、电话和所属支行数据。

## 3.2.0 资源池运营与列表易用性

- IP 资源池改为“支行 → 网点 → 地址段”三级筛选，支持按 IP、申请人姓名和统一认证号检索；已分配项展示使用人姓名和统一认证号。
- 资源池提供首页、末页和输入页码跳转；网点、网点信息列表改为每页 20 条并支持跳转。网点信息 Excel 导入、网点单条新增和批量导入均调整至列表后的低频区域。
- 地址段列表新增支行、状态和 CIDR/网点名称筛选。
- 管理员可填写原因强制释放已分配 IP，系统保留释放事件和审计；审批最终确认前自动 Ping 所选 IP，收到响应时显示可能占用警示。Ping 无响应不等同于地址空闲。

- 新增科技管理员本人已分配 IP 的二次确认后立即释放；已释放 IP 和资源编码可再次申请。
- 新增管理员站内释放通知、已读状态与释放记录筛选。
- 新增资源概览、支行使用率 Canvas 图表和完整数据表。
- 新增 IP 资源池、申请、当前分配、已释放和资源统计的 CSV/XLSX 安全导出。
- 数据库从 V006 连续增量升级至 V007；安装前自动生成 SQLite 备份，原库不删除。
