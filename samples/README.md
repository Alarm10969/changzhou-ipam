# 阶段二批量导入测试数据

1. 先在“支行”页面单条创建并启用测试支行：编号 `TEST001`，名称可填写“批量导入测试支行”。
2. 在“网点”页面上传 `test-outlets.csv`，预览通过后确认导入。
3. 在“地址段”页面上传 `test-ip-ranges.csv`，预览通过后确认导入。
4. 地址段确认成功后，在“IP 资源池”页面上传 `test-ip-pool.csv`，预览通过后确认导入。
5. 使用科技管理员重新提交一笔申请，支行选择“批量导入测试支行”，网点选择“批量导入测试网点”。管理员审批这笔新申请时会显示 9 个可分配 IP。

可用 IP 只匹配申请所属支行。此前已提交到其他支行的待审批申请不会显示 `TEST001` 的地址池，这是系统的跨支行隔离规则。

样例包含 1 个网点和该网点唯一绑定的 1 个 `/24` 地址段。确认地址段后，系统自动生成 254 个主机地址：网关自动设为系统保留，其余 253 个默认可用。`test-ip-pool.csv` 用来批量调整其中 4 个地址的状态，而不是创建整个地址池。所有数据均使用 RFC 1918 私有地址，仅供测试。
